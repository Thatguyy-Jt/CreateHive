# Scaffold Fixes

## Goal

Fix four problems in the scaffold so Phase 1 work starts from a project that builds and follows the AGENTS.md workflow without errors.

## Skills Read

None. This is project housekeeping and does not touch Clerk or Supabase.

## Existing Code Inspected

- `package.json`: scripts are `dev`, `build`, `start` and `lint`. There is no `typecheck`. `packageManager` is `pnpm@9.15.0`.
- `pnpm-lock.yaml`: the only lockfile.
- `AGENTS.md`: the working copy replaced the `next dev`-managed `<!-- BEGIN:nextjs-agent-rules -->` block with the product spec. §3 Step 9 says to run `npm run typecheck`, `npm run lint` and `npm run build`.
- `app/page.tsx`: 0 bytes, so it has no default export.
- `app/layout.tsx`: metadata is still "Create Next App" / "Generated by create next app".
- `next-env.d.ts`: imports `.next/dev/types/*`. The global `LayoutProps` type depends on generated route types.
- `node_modules/next/dist/docs/01-app/03-api-reference/06-cli/next.md`: recommends `next typegen && tsc --noEmit` for type checking outside `dev`/`build`.

## Decisions / Assumptions

1. **Package manager: pnpm.** The lockfile and the `packageManager` field already pick pnpm. AGENTS.md commands will change from `npm run …` to `pnpm …`.
2. **Typecheck script:** `"typecheck": "next typegen && tsc --noEmit"`. Plain `tsc` would fail on `LayoutProps` in a clean checkout because the route types haven't been generated yet.
3. **AGENTS.md:** keep the product spec and put the original Next.js agent-rules block back at the top, unchanged and with its BEGIN/END markers, so `next dev` stops re-creating the diff.
4. **Home page:** a small, honest placeholder landing page for "AI Creator Strategist" that says what the product is and that it is in early development. It will have no buttons or links to features that don't exist yet (AGENTS.md §14). It's a static Server Component.
5. **Metadata:** set the title to "AI Creator Strategist" and use a one-line product description.
6. `CLAUDE.md` stays empty. It isn't broken, and filling it is a separate decision.

1. Run `pnpm dev` and open http://localhost:3000.
2. Confirm the "AI Creator Strategist" heading and description appear and the browser tab title matches.

4. Narrow the window to about 375px and confirm there's no horizontal scroll.
5. Stop the dev server and check that `git diff AGENTS.md` doesn't show the Next.js block being re-added.
